# MoRe Jupiter Description

Usa [Bun](https://bun.com/) come runtime, [PicoCSS](https://picocss.com/) per lo stile e [Alpine.js](https://alpinejs.dev/) per robe che fanno robe del frontend.

Per installare le dipendenze:

```bash
bun install
```

Esegui in dev:

```bash
bun dev
```

Esegui in prod:

```bash
bun start
```

_(Bun => non esiste la build, esegue diretto in TypeScript)_
